# nlp_embedding_learning
聚焦中文NLP文本嵌入（Embedding）技术的学习与工程化实现仓库，覆盖从数据处理、模型训练到推理应用的全流程，以LCQMC中文问答匹配数据集为核心落地场景，兼顾入门学习与工程化复用。

## 项目核心
### 🔥 核心目标
- 系统学习中文文本嵌入技术（从基础原理到LoRA微调、检索规模化优化）；
- 提供可复用的文本嵌入模型训练/推理工程模板；
- 落地中文文本检索/问答匹配等下游场景。

### 🎯 核心特色
- **场景聚焦**：主打中文文本嵌入，基于经典LCQMC问答匹配任务落地；
- **全链路覆盖**：数据处理→模型定义→训练引擎→推理应用，技术栈完整；
- **学习友好**：分版本教程文档+研发过程记录，适配从入门到进阶的学习路径；
- **工程化落地**：配套参数配置、依赖清单、序列化工具，易复现、易部署。

## 目录结构与核心文件
| 目录/文件                | 核心功能                                                                 |
|--------------------------|--------------------------------------------------------------------------|
| `app.py`                 | 应用入口，封装嵌入生成、文本检索/匹配Demo、接口化调用逻辑                |
| `data.py`                | 数据处理核心，负责LCQMC数据集加载、预处理、训练/验证集构建               |
| `engine.py`              | 核心引擎，封装训练/推理/检索匹配逻辑，统一全流程执行范式                 |
| `model.py`               | 模型定义，实现基于预训练模型+LoRA的文本嵌入模型结构                     |
| `train.py`               | 训练脚本，完整实现嵌入模型的训练、验证、保存/加载流程                   |
| `pkl.py`                 | 序列化工具，通过pickle保存/加载数据集、嵌入向量等中间结果               |
| `参数设置.txt`           | 中文参数配置文件，记录训练/模型/数据相关参数（学习率、批次大小等）       |
| `data/`                  | LCQMC数据集适配目录，含数据格式转换脚本与不同规模数据集子集             |
| `docs/`                  | 分版本教程文档（基础嵌入→LoRA微调→检索规模化优化）                     |
| `findings.md/progress.md`| 研发过程记录，含实验结论、开发进度，辅助技术学习与迭代                  |
| `requirements.txt`       | Python依赖清单，一键搭建运行环境                                        |

## 教程文档
- `docs/v1_nlp_embedding_tutorial.md`：基础教程，讲解文本嵌入核心概念与基础实现；
- `docs/v2_pretrained_and_lora_tutorial.md`：进阶教程，聚焦预训练模型+LoRA微调优化嵌入；
- `docs/v3_retrieval_scale_and_advanced_training.md`：高级教程，覆盖检索场景规模化、对比学习等进阶优化。

## 快速开始
### 环境搭建
```bash
# 安装依赖
pip install -r requirements.txt
```

### 核心流程
1. 数据准备：通过`data/convert.py`处理LCQMC数据集；
2. 模型训练：修改`参数设置.txt`后执行`python train.py`；
3. 推理应用：运行`python app.py`体验文本嵌入生成/检索匹配。

## 适用场景
- 学习中文文本嵌入的核心原理与工程实现；
- 快速训练/部署中文文本嵌入模型；
- 落地文本检索、问答匹配、文档聚类等下游任务；
- 参考NLP模型的工程化封装（训练引擎、推理接口）。
